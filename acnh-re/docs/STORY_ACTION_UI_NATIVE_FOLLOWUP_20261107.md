# Story native action and UI routing follow-up — ACNH 1.0.0

This bounded trace uses the baseline EventFlow and ExeFS indexes plus the supplied supplemental animation and layout projections. It resolves part of the numeric NPC action path to internal state-machine indices, but no named clip. It also links several UI actions to same-named page configuration and BFLYT candidates, while the native action code stops at shared UI-manager calls. Read-only native and supplemental source outputs linked below come from the sibling analysis root /workspace/acnh-re; the baseline game source root is /workspace/downloads/ACNH_island_RE/ACNH_island_RE. The new artifacts and EventFlow tree exports are in this checkout. The complete node and source ledger is [the JSON artifact](../output/gameplay/story_action_ui_native_followup_20261107.json).

This establishes a static ActionIdx-to-numeric-state-slot route for cases 1–3 and a global-valued route for case 0. The code indexes internal states; it does not label them with AnimationInfo keys or ASB node names.

The AnimationInfo index still supplies no numeric action mapping. ActionIdx-to-clip remains OPEN.
